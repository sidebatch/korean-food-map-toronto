# 토론토 한인맛집 맵 (시제품)

토론토 한인식당만 모아 보여주는 지도 우선(map-first) 웹앱 시제품입니다.

- **맵 우선**: 열면 풀스크린 지도가 먼저 뜨고, 식당 이름이 작은 말풍선으로 지도 위에 표시됩니다.
- **미니멀 베이스맵**: Esri World Light Gray — 길은 보이되 공원·숲 등 부가 정보는 튀지 않게.
- **줌 겹침 해소**: 줌이 낮으면 점만 표시하고, 줌인할수록 겹쳐 숨었던 말풍선이 하나씩 드러납니다.
- **선택하면 간략히**: 말풍선을 누르면 이름·분류·한 줄 메모·주소가 뜨고, 길찾기/구글맵으로 연결됩니다.

## 데이터
토론토 코리아타운 7곳 + 노스욕 9곳, 총 16곳 (v0.4). 공개 자료와 지오코딩으로 좌표를 확인한 곳만 수록했습니다. 영업시간·메뉴 등 실시간 정보는 구글맵 링크에서 확인하세요.

## 기술
단일 `index.html` + Leaflet + Esri Light Gray 타일. 빌드 과정 없이 GitHub Pages로 바로 배포됩니다.
